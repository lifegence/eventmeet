# Sample custom CSS and header / footer HTML

In **Seminar Settings > Website Design**, set **Design** to **Custom** and copy these in:

| File | Field |
|---|---|
| `custom.css` | Custom CSS |
| `header.html` | Header HTML |
| `footer.html` | Footer HTML |

The texts are in Japanese and the company is fictitious; replace them with your own. See the
[website design guide](../../docs/en/website-design.md#34-example-custom-css-with-header-and-footer) for
screenshots.
