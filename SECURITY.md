# Security Policy

## Reporting a vulnerability

Please report security issues privately by e-mail to **contact@lifegence.com**, not in a public
issue. Include the affected version, the steps to reproduce and the impact you observed.

We will acknowledge the report within 5 business days and agree on a disclosure date with you.

## Supported versions

Security fixes are made on the latest release on the `main` branch.

## Scope

This policy covers this app (`eventmeet`). Issues in Frappe, Zoom, Google Workspace or Stripe
themselves should be reported to those projects or vendors.

The guest-reachable endpoints and their authorization, input validation and rate limits are listed in
[docs/security/guest-endpoint-audit.md](docs/security/guest-endpoint-audit.md).
